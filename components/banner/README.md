# UIKit inspired Banner Component

## Introduction
Adds a UIKit based SDC banner component.

UIKit doesn't have a banner component, so there is no specific documentation to
link out to. It makes use of a variety of CSS classes from UIKit to create a
full-width fixed-height banner image that can optionally include overlaying a
title and summary if you ensure adequate contrast when selecting your
background image for legibility. Additionally, a caption can be provided if the
image is more than simple decoration.
