# UIKit Nav Component

## Introduction

Adds a SDC Nav component which supports UIKit markup and classes.

Relevant UIKit documentation:
- [Nav component](https://getuikit.com/docs/nav)

## Features & Usage

Configuration for the `exhibit_components` module includes a `UIKit Nav` Paragraph type. This type uses fields that are passed through a paragraph template to display the component with UIKit markup.

### Component Properties
- `items`: An associative array of items to display in the nav. Each item should have a `title` and `url` key. Generated by the paragraph template.
